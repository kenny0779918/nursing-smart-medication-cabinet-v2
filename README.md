# 護理部智慧藥櫃 Prototype V2

## 已完成模組

- 人員識別證登入、角色權限首頁及共用 Header
- 取藥類型選擇
- 管制藥主管二次驗證
- 處方籤條碼與 HIS API 模擬
- 處方藥品逐項取藥、標籤列印、藥盒開關
- 實際棄藥量輸入
- 每項藥品完成後的空瓶／包材回收
- 取藥完成與稽核紀錄提示

## Prototype 測試資料

- 護理人員：`N001162`
- 護理主管：`S000888`
- 處方籤：`RX20251020001`

## 管制藥測試流程

1. 使用護理人員或主管登入。
2. 點選「取藥」。
3. 點選「管制藥取藥」。
4. 使用 `S000888` 完成二次驗證。
5. 使用 `RX20251020001` 查詢模擬處方。
6. 依序模擬關閉取藥盒及空瓶回收盒，直到完成。

目前所有管制藥示範資料暫設為需要回收空瓶／包材；之後可依正式需求修改 `requiresReturn` 設定。

以 Vue 3＋Vite 製作的需求驗證用動態原型。目前不連接真實醫療資料、藥櫃硬體或正式資料庫。

## 頁面範圍

1. Barcode輸入及模擬刷卡登入
2. 護理人員／護理主管角色權限
3. 無權限提示及3秒自動返回
4. 共用Header及5項設備狀態
5. 8項功能首頁及無權限反灰
6. 登入後閒置5分鐘自動登出
7. 管制藥逐項取藥與空瓶回收流程

測試條碼：護理人員 `N001162`；護理主管 `S000888`；其他條碼會顯示無權限。

## 檔案分工

- `src/App.vue`：登入、首頁、權限及模組入口
- `src/components/SystemHeader.vue`：共用系統 Header 與五項設備狀態
- `src/components/ControlledDispense.vue`：管制藥取藥完整流程
- `src/data/medicines.js`：模擬藥品及取藥紀錄
- `src/styles.css`：全站樣式、卡片與響應式排版
- `src/main.js`：Vue 啟動入口

## 啟動方式

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的網址即可操作。
